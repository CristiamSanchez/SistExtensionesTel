# Release Notes

## Versión 1.0 - Portfolio Demo

Esta versión entrega una solución completa de gestión de extensiones telefónicas con:

- CRUD funcional con validaciones de negocio
- autenticación basada en ASP.NET Identity
- integración con SQL Server y Docker Compose
- documentación profesional para GitHub
- pipeline básica de CI con GitHub Actions

### Destacados

- la app puede ejecutarse de forma reproducible con Docker
- el proyecto quedó preparado para ser compartido como evidencia técnica
- el README ahora está orientado a portfolio y presentación profesional
